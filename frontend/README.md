# One Take 前端

基于 React 19 + Vite 7 的现代化 AI 视频文本化剪辑工作台。

## ✨ 核心特性

- 🖥️ **双栏专业工作台 (Studio Layout)**：左侧视频播放器与指标常驻，右侧逐字稿独立平滑滚动，大文本剪辑不丢失画面焦点。
- 🎬 **实时字幕预览**：字号、字体、文字色、描边色与位置调节即时在原视频画面呈现。分句与样式使用统一规则，启用字幕时按同样参数烧录到导出视频。
- ⏩ **倍速播放控制**：支持 1.0x / 1.25x / 1.5x / 2.0x 快速切换，配合 ⏪/⏩ 快进快退，大幅提高审校效率。
- 📝 **结构化逐字稿 (按句分块)**：智能依据停顿与标点分段展示，每段标明时间戳，点击句首 ▶ 开始试听并在句尾停止；零时长句块不可播放。
- 🎯 **播放自动平滑滚动 (Auto-scroll)**：音视频播放时，逐字稿将当前发音词平滑滚动到可见区域。
- 📊 **剪辑成片动态重算**：删除/恢复词语时，前端实时计算已精简时长与剩余预估时长。
- 💾 **手动保存与防误触**：带呼吸指示灯的保存状态胶囊徽章（已保存/未保存/保存中），手动保存、导出前保存；刷新/关闭及工具栏返回有未保存提示。
- 🌙 **自适应暗黑/亮色主题**：内置专业暗黑剪辑调色板与亮色模式，支持一键切换。
- ⌨️ **快捷键速查模态框**：按需呼出键盘操作指南（空格播放、Delete 删除、方向键跳转、Ctrl+Z 撤销等）。

## 🚀 安装和运行

```bash
cd frontend
npm ci
npm run dev
```

本地访问：`http://localhost:5173`

## ⚙️ 网络与代理配置

- **本地开发**：默认同源访问，无需创建 `.env`。Vite 将 `/api`、`/health` 和 `/ws` 自动代理到 `127.0.0.1:8000`。
- **Docker 生产部署**：由同源 Nginx 统一代理静态资源与后端接口。
- **独立后端部署**：如后端部署在独立域名，可在 `.env` 中配置：

```env
VITE_API_BASE=https://api.example.com
```

HTTP API、媒体下载和 WebSocket 都会使用该基址。修改环境变量后需要重新构建；HTTPS 页面需连接 HTTPS 后端。

## 已知限制

- 启用字幕后，MP4/MOV/AVI 都使用硬字幕，导出后不能关闭字幕，需要带 libass 的 FFmpeg。
- 字号等参数按 216 高的逻辑画布缩放；预览与导出使用同一分句规则。浏览器与 FFmpeg 字体渲染存在差异，缺少所选字体时会回退，不能保证逐像素一致。描边粗细当前固定为 2，没有独立调节控件。
- 字幕中的反斜线和花括号使用全角字符显示，避免被 ASS 当成控制指令；文本自动换行，浏览器和 FFmpeg 的断行位置可能略有差别。
- 预览播放原媒体，不实时跳过删除片段；成片时长是前端估算，未完整计入静音删除和帧/音频编码边界。
- 界面目前只导出 MP4；MOV/AVI 由后端 API 支持。质量选项只控制编码，不改变分辨率。纯音频页面禁用视频导出。
- 文稿没有虚拟化；保存是手动或导出前执行，不是编辑后自动保存。SPA 浏览器后退未拦截。

## 🛠️ 技术栈

- **UI 核心**：React 19.2 + React DOM 19.2
- **路由管理**：React Router 7.12
- **构建工具**：Vite 7
- **音频可视化**：Wavesurfer.js 7.12
- **网络通信**：Axios 1.13 + 原生 WebSocket（连接失败时使用 HTTP 轮询兜底，不是自动重连）
