# One Take 前端

基于 React + Vite 的视频编辑前端界面。

## 安装和运行

```bash
cd frontend
npm install
npm run dev
```

访问 http://localhost:5173

## 配置

创建 `.env` 文件：

```
VITE_API_BASE=http://localhost:8000
```

## 功能

- ✅ 文件上传
- ✅ ASR 转写状态轮询
- ✅ 逐字稿编辑（点击切换删除状态）
- ✅ 视频导出和下载
- ⏸️ 视频播放器集成
- ⏸️ 视频文本同步
- ⏸️ 波形图可视化

## 技术栈

- React 18
- Vite 7
- React Router
- Axios
